## 一、战略定位

### 核心命题

```
不是做 AI 工具，而是做 AI 原生的垂直行业操作系统
壁垒不在于功能，而在于数据飞轮 + 工作流嵌入 + 人格资产
```

### 为什么是投资 + 教育

| 维度 | 投资（InvestMind） | 教育（EduStar） |
|------|-------------------|----------------|
| 用户规模 | 小，但 ARPU 极高 | 大，网络效应强 |
| 付费意愿 | 强，决策链短 | 中，订阅模式 |
| AI 价值 | 信息处理 + 研究加速 | 内容生产 + 个性化 |
| 数字人需求 | 路演 / 内容输出 | 讲师分身（核心需求）|
| 数据壁垒 | 研究偏好 + 投资逻辑 | 学员行为 + 内容效果 |
| 协同点 | 投资内容 → 教育课程，共享 AI 引擎 | ← |

## 三、四大 AI 引擎（共享基础设施）

### MemoryOS — 记忆引擎
```
核心价值：用户知识资产的持久化和智能检索
技术：pgvector 语义检索 + Neo4j 知识图谱 + BM25 混合排序
壁垒：用户数据不可迁移，越用越聪明
```

### AgentOS — Agent 编排引擎
```
核心价值：复杂多步骤任务的自动化执行
技术：LangGraph 状态机 + 工具注册表 + 人机协作暂停
壁垒：深度工作流嵌入，替换成本极高
```

### AvatarOS — 数字人引擎
```
核心价值：用户人格的数字化复制与内容生产
技术：HeyGen API + ElevenLabs + 异步生成流水线
壁垒：用户声音/形象数据形成个人专属资产
```

### PerceptOS — 多模态引擎
```
核心价值：任意格式内容的结构化理解
技术：Claude Vision + Gemini 长上下文 + NER 提取
壁垒：行业专属内容理解能力随数据积累持续提升
```

## 四、数据飞轮机制

### InvestMind 飞轮
```
用户分析行为
    ↓
偏好数据沉淀（关注什么公司/行业/指标）
    ↓
推荐越来越精准 → 用户依赖度提升
    ↓
更多用户加入（口碑：效率提升可量化）
    ↓
行业知识图谱越来越丰富
    ↓
产品能力远超竞品 → 形成壁垒
```

### EduStar 飞轮
```
讲师生产内容
    ↓
学员学习行为数据（哪里不懂/哪里快进）
    ↓
内容效果分析 → 讲师优化课程
    ↓
完课率提升 → 学员推荐 → 更多学员
    ↓
更多讲师入驻（学员基础大）
    ↓
平台内容越来越丰富 → 网络效应形成
```

### 双飞轮交叉协同
```
投资分析师 → 生产财经分析内容 → EduStar 开课变现
EduStar 学员行为数据 → 反哺内容推荐 → InvestMind 更精准
两个产品共享用户（同一批高净值、高学习意愿人群）
```

## 五、竞争壁垒构建路径

### 阶段一（0-6个月）：跑通 PMF
```
目标：找到愿意持续付费的核心用户
行动：InvestMind MVP 上线，50个付费用户
壁垒建立：用户投资笔记开始在 MemoryOS 积累
```

### 阶段二（6-18个月）：数据飞轮启动
```
目标：用户黏性显著高于竞品
行动：EduStar 上线，两产品数据打通
壁垒建立：个人知识图谱足够丰富，用户不愿迁移
```

### 阶段三（18个月+）：平台化
```
目标：从工具变成平台，建立网络效应
行动：AI 员工市场，开发者 API
壁垒建立：三重壁垒（数据 + 网络效应 + 工作流嵌入）
```

## 七、技术风险与应对

| 风险 | 概率 | 应对 |
|------|------|------|
| HeyGen API 涨价/断供 | 中 | 积累数据后自研，或多供应商切换 |
| Claude API 成本超预算 | 高 | 模型路由策略，Prompt 缓存 |
| 大厂做同类产品 | 高 | 深耕垂直数据，做大厂不愿做的长尾 |
| 数据安全合规 | 中 | RLS 隔离，国内数据本地化存储 |
| 金融内容监管 | 中 | 所有 AI 输出加免责声明，不做荐股 |
