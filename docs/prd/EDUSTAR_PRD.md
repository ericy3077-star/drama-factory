## 1. 产品愿景

### 一句话定位

> **EduStar 是知识创作者的 AI 课程工厂——让内容生产成本降低90%，让每个讲师都有专属数字分身。**

### 核心问题

知识付费行业有一个根本矛盾：**内容生产是线性的，但内容消费是指数级的**。一个顶级讲师每天最多讲8小时课，但课程需求可能要求他每天"出现"在100个不同场景——直播、录播、问答、企业内训定制版。

当前的解法是"请更多讲师"或"讲师拼命录课"，前者稀释品牌，后者烧掉讲师。EduStar 的解法是：**用一次性的数字人训练，创建一个可以无限复制的内容生产线**。

我们不是视频剪辑工具，也不是PPT生成器。EduStar 的核心是将三件事串成自动化流水线：讲师的知识体系（AgentOS 提炼大纲+脚本）→ 讲师的形象声音（AvatarOS 数字人克隆）→ 可交付的课程视频（HeyGen 视频生成）。三个环节缺一不可，完整的流水线才是护城河。

## 2. 目标用户（Personas）

### P1：知识付费讲师（核心用户，最高 LTV）

**人口属性**：28-45岁，课程博主/训练营创始人/垂直领域专家，已有一定粉丝基础（抖音/微信/小红书1万-100万粉），主要变现方式为知识星球/私教/训练营，年收入50万-500万。

**工作场景**：
- 每月需要产出4-8节新课内容（保持更新频率维持付费用户活跃）
- 经常需要针对不同人群出"定制化"版本（小白版/进阶版/企业定制版），实质上是同一知识体系的不同包装
- 花大量时间在"讲课"本身之外：写脚本（2-4小时/节）、录制+剪辑（3-5小时/节）、字幕/封面（1小时/节）
- 有明确的个人IP形象，对输出内容的"风格一致性"要求高

**核心痛点**：
1. **内容生产是瓶颈**：有知识储备，但生产速度远跟不上商业需求，课程交付周期制约变现
2. **重复劳动消耗创意**：大量时间花在录制、剪辑等非核心工作，真正用于深度思考内容的时间被压缩
3. **个人形象难以规模化**：分身乏术，无法同时出现在多个课程/平台，品牌影响力受物理限制
4. **企业定制需求无力承接**：企业采购内训内容需要大量定制视频，讲师没有产能，错失高客单价B端市场

**使用频次**：每周2-3次集中使用（批量生产模式），而非每天高频碎片使用。

**付费预期**：B端视角，把 EduStar 当生产工具计算ROI。原本外包视频制作1分钟约¥500-1000，如果 EduStar 能把成本降到¥50/分钟，愿意付年费¥2-5万。付费决策周期短，见到演示demo就能拍板。

---

### P2：企业 L&D 负责人（高价值B端用户）

**人口属性**：30-45岁，大中型企业（500人以上）人力资源/培训负责人，掌握年度培训预算（一般50-500万），需要向上汇报培训效果，向下交付高质量培训内容。

**工作场景**：
- 每年需要制作/采购20-100节内部培训课程（入职培训、合规培训、产品培训、技能培训）
- 现有方式：外采标准课程（贵且不贴合）+ 内部讲师录制（质量参差不齐）
- 内部讲师（业务专家）往往有知识但没有表达能力，出镜拍视频意愿低
- 培训内容需要频繁更新（产品迭代、制度变更），每次更新都要重新录制

**核心痛点**：
1. **制作成本高**：高质量培训视频外包制作成本高，且周期长（2-4周/节）
2. **内容更新麻烦**：产品更新后，旧视频的错误内容必须重新录制，不能只改文字
3. **内部讲师出镜难**：技术专家/业务骨干有知识没时间，不愿意花时间录视频
4. **个性化程度不足**：标准采购课程无法体现公司文化，员工参与度低

**使用频次**：项目制使用，每季度集中批量生产。

**付费预期**：企业采购流程，需要正规报价+合同+发票。基础功能包年约¥10-20万，大型企业私有化部署报价更高。决策周期较长（1-3个月），需要演示+POC+商务谈判。

---

### P3：在线教育机构内容团队（规模化用户）

**人口属性**：20-35岁，在线教育平台/K12机构的内容制作团队成员（课程编辑、教研、视频制作），团队规模5-50人，平台有自己的用户群但内容产能不足。

**工作场景**：
- 有明确的课程研发计划（月/季度），但执行速度受制于视频生产产能
- 已有稳定的脚本生产流程，缺的是从脚本到视频的高效生产
- 有品质标准，但不需要顶级效果，需要的是稳定且足够好
- 对多语言版本有需求（东南亚市场、港澳台市场）

**核心痛点**：
1. **视频生产产能不足**：有脚本没有足够的录制/制作人力，视频生产是最大瓶颈
2. **讲师档期协调困难**：讲师需要提前排期，临时变更成本高
3. **多语言版本成本高**：同一课程出英文/粤语/泰语版，录制成本翻倍
4. **视觉风格不统一**：多个讲师背景、光线、服装各异，整体课程视觉一致性差

**使用频次**：每日使用，工作流嵌入式，是团队日常生产工具。

**付费预期**：团队席位制，¥5-15万/年，需要多用户协作功能和项目管理能力。

## 3. 用户旅程

### Stage 0：种草（Day -30 ~ Day 0）

**触点**：
- 抖音/视频号上刷到"AI生成讲师视频"的演示（最高转化渠道，视觉震撼）
- 知识付费圈/HR圈社群里的案例分享（同行推荐，可信度高）
- 搜索"AI数字人课程制作"、"数字人训练"等关键词
- 课程制作工具测评类内容（B站/知乎）

**用户心理差异**：P1讲师的核心疑问是"这个数字人像不像我？"；P2企业HR的核心疑问是"内容质量够不够，能不能让员工真正学进去？"；P3机构团队的核心疑问是"接入流程麻烦不麻烦，能不能融入我们现有的工作流？"

---

### Stage 1：注册与 Demo（Day 0）

**关键设计原则**：EduStar 的 Aha Moment 不同于 InvestMind——用户必须看到真实的数字人视频样本才会被说服，文字描述完全不够。

**注册流程**：
- 访问官网 → 看 Demo 视频（真实讲师克隆案例，不是渲染效果图）→ 点击"免费体验" → 邮箱注册
- 注册后立即进入引导页面，可以用**系统预置的样本讲师**体验完整的"脚本→视频"流程（不需要先上传自己的素材），5分钟内看到输出视频

**免费体验定位**：让用户体验到"从脚本到视频"的完整流程和质量，证明技术可行性。但免费版不支持训练自己的数字人，训练是付费门槛。

---

### Stage 2：Onboarding（Day 0-7）

**用户类型分流**：
- 讲师用户：引导至"训练我的数字人"流程，提供素材采集指南
- 企业用户：引导至"样本数字人"模板库，先体验课程工厂再决定是否定制数字人
- 机构团队：引导至"批量生产"工作台，演示 CSV/批量上传脚本→批量生成视频的工作流

**讲师用户关键节点**：
- Day 0-3：阅读素材采集指南，准备拍摄素材
- Day 3-7：上传素材，提交训练请求（训练耗时24-72小时）
- Day 7+：数字人就绪，完成第一条视频生成，进入正式使用阶段

**激活标准**：首次成功生成视频（非预置样本，而是使用自己训练的数字人）= 激活完成。这个标准比 InvestMind 更严格，但也意味着激活的用户流失率极低。

---

### Stage 3：初步使用（Day 7-30）

**讲师用户高频行为**：
- 用 AI 课程工厂输入课程主题，生成大纲
- 对大纲修改后，批量生成分节脚本
- 提交视频生成任务（批量或单个）
- 在平台上预览生成视频，下载/发布

**满意度决定性时刻**：第一次看到自己的数字人说话的那一刻。这是产品口碑的核心节点——用户要么感动（"太像了"），要么失望（"感觉很假"）。训练质量和素材质量是决定因素。

---

### Stage 4：付费转化（Day 14-45）

**付费转化路径**：
- 讲师：试用期内生成了X分钟视频后达到免费上限 → 展示已节省的时间/成本 → 订阅月付/年付
- 企业：演示阶段结束 → 商务对接 → 签合同（通常需要销售人员介入）
- 机构：功能验证后 → 团队账户升级

**企业用户特殊处理**：企业用户需要走采购流程，系统需要支持"商务询价"入口，提交需求后由销售跟进，不能指望企业用户自助完成Stripe付款。

---

### Stage 5：深度使用（Day 30+）

**深度使用飞轮**：
- 数字人训练完成 → 生成视频越多 → 对数字人质量了解越深 → 对脚本格式越熟练 → 生产效率持续提升
- 课程工厂积累的大纲/脚本模板 → 下次同类课程生产更快
- 学员数据（看到哪一节流失）→ 反馈到下次课程设计

**留存壁垒**：数字人模型是用户自己训练的，无法迁移到其他平台。这是比 MemoryOS 更强的留存机制——数字人资产绑定在 EduStar 上。

---

### Stage 6：口碑传播（Day 60+）

**主要传播场景**：
- 讲师在直播/社群中展示自己的"数字分身"生成的视频，天然带话题性（"这真的是AI生成的？！"）
- 企业HR在HR圈子分享"AI内训视频"案例
- 生成的视频分享到课程平台时，自动带 EduStar 水印（用户可付费去除），带来被动曝光

## 5. P0 功能用户故事与验收标准

### 5.1 数字人素材采集与质检

**用户故事**

> 作为知识付费讲师，我希望上传自己拍摄的视频素材后，系统能立即告诉我素材是否合格以及哪里需要改进，以便我不需要等待训练失败才知道素材有问题，避免重复拍摄的时间浪费。

**验收标准（AC）**：

1. **AC-1 质检时效**：素材上传完成后，自动质检在 60 秒内完成并返回报告，不需要人工干预。
2. **AC-2 质检维度覆盖**：质检报告必须包含以下六个维度的评分（通过/警告/不合格）：视频分辨率（≥1080p）、帧率（≥25fps）、时长（2-10分钟）、人脸清晰度（无遮挡、无模糊）、背景干净程度（纯色或简洁背景）、音频质量（无明显噪音、无回声）。
3. **AC-3 改进建议具体化**：对每个"警告"或"不合格"项，提供具体的改进建议，而不是笼统提示。例如不是说"背景不合格"，而是说"检测到背景中有移动物体（右下角），建议重新拍摄时确保背景区域无人员走动"。
4. **AC-4 部分合格可继续**：质检结果只要不含"不合格"项（全部为通过或警告），用户可以选择继续提交训练，系统显示"存在X个警告项，可能影响训练效果，是否继续？"由用户决策。
5. **AC-5 质检历史**：用户可查看历次上传素材的质检历史记录，方便对比改进效果。

---

### 5.2 数字人训练

**用户故事**

> 作为知识付费讲师，我希望提交训练请求后能实时看到训练进度，在训练完成时第一时间收到通知，以便我可以合理安排其他工作，不需要一直盯着页面刷新。

**验收标准（AC）**：

1. **AC-1 训练任务提交**：用户提交训练后，系统返回任务ID，并在界面上显示"排队中/训练中/完成/失败"四种状态之一，状态更新通过 WebSocket 推送，无需刷新页面。
2. **AC-2 进度可视化**：训练中状态下，显示预估剩余时间（基于历史训练时长统计），误差不超过±30%。
3. **AC-3 完成通知双渠道**：训练完成（成功或失败）后，站内通知立即推送，同时发送邮件通知（邮件在10分钟内到达）。失败通知必须包含失败原因分类（素材问题/服务问题/配额问题）。
4. **AC-4 训练结果预览**：训练成功后，系统自动生成一段 15 秒的数字人示例视频（使用预设测试脚本），用户可在"我的数字人"页面立即预览，无需额外操作。
5. **AC-5 失败重试机制**：若训练失败原因为"服务问题"（HeyGen API 故障等），系统自动重试最多2次，每次间隔30分钟，重试期间用户可看到"自动重试中"状态，不需要手动重新提交。

---

### 5.3 视频生成

**用户故事**

> 作为企业 L&D 负责人，我希望粘贴一段课程脚本文字后，数字人讲师能在30分钟内生成对应的讲解视频，以便我快速验证内容质量，而不需要安排真人讲师档期和视频制作团队。

**验收标准（AC）**：

1. **AC-1 脚本长度支持**：单次视频生成支持脚本字数 100-3000 字，对应约1-20分钟视频。超过3000字的内容，系统建议拆分为多个视频并提供拆分辅助工具。
2. **AC-2 生成时效**：5分钟以内的视频（约750字脚本），从提交到可预览，处理时间 ≤ 30分钟（含 HeyGen 排队时间）。系统应在提交时给出预估完成时间。
3. **AC-3 字幕自动生成**：每个生成的视频自动配备中文字幕（SRT格式），字幕与音频对齐误差 ≤ 0.5秒。用户可下载 SRT 文件或直接在视频中嵌入字幕。
4. **AC-4 视频下载格式**：支持下载 MP4（H.264, 1080p）格式，文件大小在合理范围内（1分钟视频 ≤ 200MB），下载链接有效期7天。
5. **AC-5 生成失败处理**：若视频生成失败，系统不消耗用户配额，并在任务详情页显示具体失败原因（脚本含违禁词/API超时/其他技术原因），提供解决指引。

---

### 5.4 基础课程管理

**用户故事**

> 作为在线教育机构内容团队成员，我希望能在平台上创建课程并管理各节视频的上下顺序，以便内容团队不需要依赖技术人员就能完成课程结构的调整和发布。

**验收标准（AC）**：

1. **AC-1 课程创建**：新建课程需填写：课程名称（必填）、简介（≤500字）、封面图（支持JPG/PNG，比例16:9）、分类标签（多选）。创建后可立即添加节课。
2. **AC-2 节课管理**：支持拖拽排序，顺序修改后自动保存，无需额外点击"保存"。单个课程最多支持500节课。
3. **AC-3 发布控制**：每节课可独立设置上架/下架状态，下架的节课学员不可见，但讲师侧仍可编辑和预览。课程整体也有上架/下架开关，下架后学员无法访问但不影响已购学员的学习记录。
4. **AC-4 视频关联**：每节课可关联一个已生成的 EduStar 视频，也可上传外部视频文件（MP4, ≤2GB）。已关联的视频可随时替换，替换后学员下次播放时自动使用新视频（已观看的进度不重置）。
5. **AC-5 操作权限**：课程的创建者（讲师账户）拥有全部权限。企业账户下可设置"内容编辑"角色，内容编辑可修改节课但不可删除课程或修改定价（为 P1 团队版功能预留接口，MVP 阶段无多角色，AC 作为占位设计要求）。

## 6. 数字人素材采集规范

这是 AvatarOS 训练质量的决定性因素，也是用户最容易在这里出问题的环节。以下规范必须以图文并茂的形式呈现在产品内（采集指南页面），而不是藏在 FAQ 里。

### 硬性要求（不符合则训练失败率极高）

**设备与分辨率**：
- 最低要求：1080p（1920×1080），30fps。推荐：4K，60fps。
- 用手机拍摄时，必须横向拍摄，不接受竖向视频（竖向会导致人脸比例异常）。
- 手机推荐：iPhone 12及以上、Android旗舰机（2020年后）。

**时长**：
- 最短2分钟，最长10分钟。少于2分钟训练样本不足；超过10分钟上传处理时间过长且收益递减。
- 整段视频讲师必须持续在画面中央，中途离开画面会导致训练失败。

**背景**：
- 纯色背景最佳（白色/浅灰/浅蓝），干净的室内环境可接受。
- 绝对禁止：绿幕（HeyGen 会误处理）、复杂花纹背景、移动背景（如电视正在播放）。
- 背景中不得有其他人物，哪怕是模糊的。

**光线**：
- 正面补光，面部均匀受光，无大面积阴影。
- 禁止逆光拍摄（背对窗户）。
- 推荐：环形补光灯，放置在讲师正前方，略高于头部。

### 软性要求（影响训练质量）

**服装**：
- 建议深色纯色服装（黑/深蓝/深灰），不要穿花纹或条纹，不要穿与背景颜色相近的衣服。
- 不要穿领子遮住脖子的衣服（高领毛衣、厚围巾），会影响头部动作的自然度。

**表情与动作**：
- 讲话时表情自然，幅度适中，避免过度夸张的表情和大幅度的肢体动作（抬手不超过肩膀高度）。
- 避免频繁低头看笔记或看手机，保持与镜头的眼神接触。
- 说话语速适中（每分钟200-300字），避免过快或过慢。

**音频**：
- 必须同期录音（手机自带麦克风可接受，外接领夹麦更好）。
- 在安静的室内录制，关闭空调和风扇（噪音会影响音频克隆质量）。
- 不接受后期配音版本（声音与口型要求自然同步）。

**内容建议**：
- 内容可以是任意话题（不需要是正式课程内容），自然讲话即可。
- 可以使用训练营/课程介绍、行业经验分享等日常话题，避免背稿式朗读。
- 建议包含：停顿、语气词（"嗯"/"对"/"所以"），这让数字人表现更自然。

### 上传前自检清单

用户提交素材前，引导其完成以下自检（产品内以 Checklist 形式呈现）：

- [ ] 视频横向拍摄，分辨率 ≥ 1080p
- [ ] 时长在 2-10 分钟之间
- [ ] 背景干净，无其他人物
- [ ] 面部光线均匀，无大面积阴影
- [ ] 全程保持在画面中央，未离开画面
- [ ] 服装为深色纯色
- [ ] 录音清晰，无明显噪音
- [ ] 未使用绿幕背景

## 7. 非功能性需求

### 性能

| 指标 | 目标值 | 备注 |
|------|--------|------|
| 素材上传速度 | 支持断点续传，100MB/s带宽上限 | 用户素材文件一般 1-5GB |
| 质检响应时间 | < 60秒 | 上传完成后自动触发 |
| 视频生成时效（5分钟视频） | < 30分钟 | 含 HeyGen 队列等待 |
| WebSocket 状态延迟 | < 2秒 | 任务状态变更到前端显示 |
| 视频播放卡顿率 | < 2%（3G网络） | CDN 加速分发 |
| 并发训练任务 | 支持50个并发 | HeyGen API 限额相关 |

### 安全与合规

- **数字人使用授权**：用户训练数字人时必须勾选"我本人授权使用我的形象和声音"，并保存时间戳。防止他人盗用他人形象训练数字人。
- **内容审核**：视频生成脚本需通过内容安全检测（调用阿里云内容安全API），拦截政治敏感/色情/违法内容。
- **版权声明**：生成视频中嵌入的音频克隆技术仅用于讲师本人克隆，不得用于克隆他人声音。平台保留撤销违规用户数字人资产的权利。
- **数据安全**：训练素材（原始视频）在训练完成后30天内可选择删除（不影响已训练的数字人模型）。

### 可用性

- **SLA**：核心生成链路月可用率 ≥ 99%（依赖 HeyGen 第三方服务，条款需与 HeyGen SLA 对齐）。
- **HeyGen 降级预案**：若 HeyGen API 不可用，系统暂停新任务提交，已提交任务保留队列，恢复后自动继续，用户收到状态通知。
- **素材存储**：原始素材和生成视频存储在 OSS，设置生命周期策略（原始素材训练后30天归档至冷存储，降低存储成本）。

## 8. 成功指标

### 北极星指标

**讲师月生成视频总分钟数（Monthly Generated Video Minutes）**

选择理由：这个指标直接反映平台为用户创造的内容价值总量。分钟数增长说明：用户在持续使用（不是注册后不用）、数字人质量被认可（质量不好不会持续生成）、课程工厂效率有效（大纲→脚本→视频流程顺畅）。同时这个指标也直接与平台的 HeyGen API 成本相关，帮助监控单位成本变化。

### 支撑指标体系

**数字人质量层**：
- 数字人训练成功率（目标 ≥ 90%，低于此说明质检引导有问题）
- 素材质检通过率（一次性通过 vs 需要重新上传，目标初次通过率 ≥ 70%）
- 训练后讲师满意度（训练完成后弹出1-5分评价，目标平均分 ≥ 4.0）

**视频生成层**：
- 视频生成成功率（目标 ≥ 95%，不含脚本违规导致的失败）
- 平均视频生成时长分布（用于优化服务器资源规划）
- 生成后下载率（目标 ≥ 80%，低于此说明质量不被认可）

**留存与商业化层**：
- 讲师月续费率（目标 ≥ 80%，数字人资产留存效果强）
- 月均视频生成分钟数/付费讲师（使用深度指标）
- 从注册到首次成功生成视频的转化率（目标 ≥ 60%）
- 企业客户年续约率（目标 ≥ 85%）

**平台健康层**：
- HeyGen API 调用成功率（< 98% 需要告警）
- 单分钟视频生成成本（持续优化目标，首年目标 < ¥3/分钟）
- 素材存储成本增长趋势（生命周期策略效果验证）

### 预警指标（出现则需立即排查）

- 数字人训练成功率 < 80%（7日滚动均值）→ 检查 HeyGen API 状态 + 质检规则
- 视频生成任务平均等待时间 > 60分钟 → 检查 HeyGen 配额和 avatar_worker 队列积压
- 讲师7日流失率 > 15%（首次生成视频后）→ 视频质量问题，需要人工复核近期生成样本
- 素材上传失败率 > 5% → 检查 OSS 配置和网络链路
