## 1. 一页纸战略（Executive Summary）

### 我们是谁

**Drama Factory 是一家 AI 超级工具公司**，通过共享的四大 AI 引擎基础设施（MemoryOS / AgentOS / AvatarOS / PerceptOS），在投资和教育两个高价值垂直赛道构建记得你、懂你业务、替你工作的 AI 助手。

一句话定位：**"让专业知识工作者拥有一个永不遗忘、持续进化的 AI 分身。"**

### 核心痛点

| 行业 | 痛点 |
|------|------|
| 投资 | 信息爆炸 × 时间稀缺：私募研究员每天处理 200+ 条信息，95% 是噪音；知识沉淀在个人脑袋里，离职即流失 |
| 教育 | 内容生产太贵太慢：一门精品课制作成本 10-50 万元，数字人讲师无法规模化；个性化停留在 PPT 时代 |

### 解决方案

- **InvestMind**：投资超级助手——AI 信息流过滤 + 研究工作台 + 记忆型投资 Agent，让一个分析师的产出翻 3 倍
- **EduStar**：教育数字人平台——讲师只需录制 5 分钟素材即可克隆数字人，自动生成多语言课程，私域学员可与 AI 讲师 7×24 互动

### 为什么能赢（核心壁垒）

1. **数据飞轮**：MemoryOS 积累的用户行为数据越多，Agent 越精准；竞品无法复制用户的私有知识图谱
2. **工作流嵌入**：深度集成研究员/讲师的日常工作流，切换成本极高（类比 Bloomberg 终端）
3. **人格资产**：讲师的数字人形象 + 投资人的投资风格偏好，是平台独有的不可迁移资产
4. **技术复用**：一套引擎撑两个赛道，边际成本极低；竞品需独立研发

### 18 个月目标

| 指标 | 目标 |
|------|------|
| InvestMind 付费用户 | 500 人（月均 ARPU ¥599） |
| EduStar 讲师用户 | 150 人（月均 ARPU ¥1,200） |
| MRR | ¥50 万+ |
| 回本周期 | 单用户 CAC 回收 < 4 个月 |
| API 外部调用收入 | ¥5 万/月 |

## 2. 市场机会分析

### 2.1 投资行业

#### 市场规模

- 中国公募基金规模 **32 万亿元**（2025），基金经理约 8,000 人，研究员约 30,000 人
- 私募行业：备案私募基金管理人 21,000+ 家，从业人员 60 万+
- 个人投资者（活跃账户）：**2.2 亿**，其中有研究习惯的重度用户保守估计 500 万
- 可服务 TAM（愿意付费的专业/半专业用户）：**约 200 万人，潜在收入规模 ¥100 亿/年**

#### 核心痛点（具体化）

1. **信息过载**：Wind 终端每日推送 3,000+ 条公告，研究员手动筛选耗时 2-3 小时/天
2. **知识孤岛**：每个分析师有独立的笔记/模型，无法团队共享；明星研究员离职后知识清零
3. **研究效率低**：一份深度研报平均耗时 40 小时；AI 助手大多只会聊天，不会真正做研究
4. **合规压力**：监管对投研分离、信息隔离要求越来越严，需要可审计的 AI 行为记录

#### 现有竞品分析

| 竞品 | 优势 | 核心局限 |
|------|------|---------|
| **Wind AI** | 数据最全，机构覆盖率高 | 界面笨重，AI 能力停留在问答层，无记忆/工作流 |
| **Bloomberg GPT** | 英文市场品牌强 | 不适配中国市场监管和数据源；中文语义理解弱 |
| **同花顺 AI** | C 端覆盖广，流量大 | 专业深度不足，沦为散户工具；无机构级私有化部署 |
| **万得通用 AI** | 整合 Wind 数据 | 本质是 RAG 包装，无真正 Agent 能力；无记忆 |
| **通用 LLM（ChatGPT/Claude）** | 推理能力强 | 无金融数据实时接入；无用户记忆；合规风险高 |

#### 差异化切入点

- **垂直 Memory**：记住用户的持仓风格、关注标的、历史判断，做到"第二个大脑"而非每次从零对话
- **工作流 Agent**：不只是回答问题，而是主动执行"帮我跟踪茅台每天的舆情变化并在异常时提醒我"
- **切入口**：私募中小基金（50-500 亿 AUM）——规模不够买彭博终端，又比散户专业，是价格敏感 + 需求真实的完美早期客户

### 2.2 教育行业

#### 市场规模

- 知识付费市场：2025 年规模 **1,500 亿元**，年增长 20%+
- 企业培训市场：**6,000 亿元**，数字化渗透率不足 30%，增长空间巨大
- 在线教育（K12 以外）：综合规模 **5,000 亿元**，头部平台如得到、混沌、36 氪学院构成主力
- 数字人教育赛道专项 TAM：内容制作工具 + 互动学习平台，**预计 2027 年达 500 亿元**

#### 核心痛点（具体化）

1. **内容生产成本高**：一门标准化在线课程（30 课时）：真人录制 ¥8-15 万，更新一次需重新拍摄
2. **讲师时间稀缺**：头部讲师（10 万+ 粉丝）无法服务长尾学员；1 对 1 辅导边际成本无法摊薄
3. **多语言出海困难**：同一套内容做英文/东南亚版本，成本翻 3 倍
4. **个性化停留在推荐算法层**：推题推课，无法做到真正"因材施教"的对话式学习

#### 现有竞品分析

| 竞品 | 优势 | 核心局限 |
|------|------|---------|
| **HeyGen** | 数字人视频质量高，国际知名 | 纯视频生成工具，无 AI 讲师互动；无教育工作流；无私域学员管理 |
| **Synthesia** | 企业级品牌，欧美市场强 | 中文口型不自然；无中国本土部署；无 Agent 能力 |
| **D-ID** | API 生态好 | 质量不稳定；无课程管理功能 |
| **腾讯课堂 AI / 网易有道** | 流量入口大 | AI 功能浅尝辄止；平台抽佣高（20-30%）；讲师数据无法自有 |
| **硅基智能/数字栩生** | 国内数字人制作能力强 | 纯 2B 定制，无 SaaS 化产品；无 Agent 互动能力 |

#### 差异化切入点

- **讲师 IP 数字永生**：不只是生成视频，而是克隆讲师的知识体系 + 表达风格，让数字人能真正回答学员问题
- **切入口**：独立知识博主 / 垂类 KOL（粉丝 1-10 万区间）——有变现需求，无团队支撑，迫切需要用 AI 降本增效

### 2.3 协同效应

#### 两个赛道如何互相增强

```
InvestMind 用户（专业人士）
      ↓ 专业内容沉淀
EduStar 讲师（知识变现）
      ↓ 学员数据 + 互动数据

两个赛道的 Agent 精准度同步提升
```

- 资深基金经理在 InvestMind 中积累的投资笔记，可一键迁移为 EduStar 课程内容

- 销售漏斗互通：InvestMind 的高净值用户是 EduStar 金融理财课程的优质受众

## 3. 竞争定位图

### 3.1 InvestMind 定位矩阵

**两个维度**：
- X 轴：行业专业深度（低 → 高）：指金融数据接入程度、合规能力、专业术语理解
- Y 轴：AI Agent 深度（低 → 高）：指从问答 → 主动执行任务的能力

```
高 AI Agent 深度
        │
        │                    ★ InvestMind
        │                    （高专业度 × 高 Agent）
        │
        │   ChatGPT/Claude
        │   （高 Agent，低专业）
        │
────────┼──────────────────────────────→ 高行业专业度
        │
        │   同花顺 AI          Wind AI / Bloomberg GPT
        │   （低 Agent，中专业） （低 Agent，高专业）
        │
低 AI Agent 深度
```

**核心结论**：InvestMind 占据右上角空白地带。Wind/Bloomberg 有数据无 Agent；ChatGPT 有 Agent 无数据；我们两者兼具且有记忆层。

---

### 3.2 EduStar 定位矩阵

**两个维度**：
- X 轴：内容生产成本（高 → 低）
- Y 轴：AI 讲师个性化程度（低 → 高）

```
高个性化程度
        │
        │                    ★ EduStar
        │                    （低成本 × 高个性化）
        │
        │   真人 1 对 1 辅导
        │   （高成本，高个性化）
        │
────────┼──────────────────────────────→ 低生产成本
        │
        │   腾讯课堂/网易    HeyGen / Synthesia
        │   （高成本，低个性化）  （低成本，低个性化）
        │
低个性化程度
```

**核心结论**：EduStar 通过 AvatarOS + MemoryOS 组合，实现"低成本 + 高个性化"——这是竞品认为不可能同时实现的组合，也是我们的核心护城河。

## 5. 去市场策略（GTM）

### 5.1 InvestMind GTM

#### 冷启动：前 50 个付费用户（具体操作）

**目标用户画像**：私募基金初级/中级研究员（3-8 年经验），年薪 30-80 万，有自费购买工具的习惯

**渠道和方法（按优先级）**：

1. **雪球 + 投资人社群（第 1-4 周）**
   - 创始人在雪球发 5 篇深度技术文章（"我如何用 AI 构建投资知识图谱"系列）
   - 每篇文章末尾附带 Beta 邀请码，限 20 人免费试用 3 个月
   - 预期：每篇转化 5-10 个真实用户，4 周获取 30+ 种子用户

2. **私募从业者微信群渗透（第 2-6 周）**
   - 加入 10-15 个私募研究员聚集的微信群（通过行业会议/LinkedIn 寻找）
   - 不发广告，先分享有价值的 AI 投研 Tips，建立信任后私信邀请体验
   - 预期：转化率 10-15%，获取 15-20 个高质量用户

3. **知乎专栏 + 即刻（持续）**
   - 以"AI 投研实践者"身份运营，重点回答"如何提高研究效率"类问题
   - 每周 1-2 篇干货，不硬广，让产品自己说话

4. **首月关键动作**：亲自陪伴前 10 个用户使用，每周 1 小时访谈，迭代产品

**前 50 用户转化目标**：
- 免费体验：50 人
- 付费转化率：60%
- 前 50 付费用户获取时间：**M1-M3**

#### 增长：口碑传播触发机制

- **"Aha Moment" 设计**：用户第一次说出"这个 AI 居然记住了我三个月前的判断"——此刻触发分享弹窗
- **推荐机制**：邀请 1 个付费用户，双方各获得 1 个月免费，上不封顶
- **研报共享**：专业版用户可选择公开自己的 AI 研究笔记（脱敏），形成社区内容 + 吸引新用户

#### 定价策略

- **前 3 个月**：邀请制免费，不收钱，但要求用户留下真实反馈（类比 Superhuman 早期策略）
- **M4 开始**：引入付费，早鸟价 7 折，永久锁定（激励早期转化）
- **免费层**：永久免费版（限 500 条记忆，每日 10 次 Agent 任务）——作为获客漏斗顶端，不作为主要收入来源

### 5.2 EduStar GTM

#### 冷启动：前 20 个讲师用户（具体操作）

**目标用户画像**：垂类知识博主，粉丝 1-20 万，有付费课程或意向出课，对 AI 工具感兴趣

**渠道和方法（按优先级）**：

1. **小红书 / 抖音 AI 工具博主圈（第 1-3 周）**
   - 定向找"分享 AI 效率工具"的博主，私信合作：免费帮他们建一个数字人，换一篇真实体验分享
   - 预期：5-8 个 KOL 自发传播，每人带来 2-5 个同类讲师

2. **垂直赛道 KOL 直接邀请（第 2-6 周）**
   - 重点赛道：职场提升、财商教育、编程学习（与 InvestMind 用户重叠）
   - 方法：找到每个赛道前 50 名讲师（用飞瓜数据/新榜筛选），逐一发送个性化邀请+免费数字人体验
   - 邀请信核心：**"我们帮你免费克隆一个数字人分身，你只需要录制 5 分钟视频"**

3. **线下课程/训练营渗透（第 3-8 周）**
   - 成为"得到学习铁三角"、混沌创新院等社群的技术分享嘉宾
   - 以工具分享为由，自然展示产品

**前 20 讲师获取时间：M1-M2（全部免费建模，换真实反馈和推荐）**

#### 增长：双边网络效应

```
讲师入驻 → 带来学员 → 学员数据提升 AI 讲师质量 → 吸引更多讲师
    ↑                                                        |
    └──────────── 平台品牌/口碑扩散 ←──────────────────────┘
```

- **讲师裂变**：讲师每邀请 1 名同行，获得 1 个月免费建模额度
- **学员侧引流**：每个 EduStar 课程页底部显示"由 AI 讲师提供支持 · Drama Factory"，反向引流
- **成功案例输出**：第一批 20 个讲师中，争取 3-5 个可量化的成功案例（如："数字人上线后，课程销量增加 40%"），作为后续推广素材

#### KOL 合作策略

| KOL 类型 | 合作形式 | 预期效果 |
|---------|---------|---------|
| AI 工具评测博主（10-50 万粉）| 免费建模 + 收入分成（学员付费的 5%）| 单篇视频带来 50-200 个注册 |
| 垂类知识 KOL（5-20 万粉）| 免费专业版 6 个月 + 内容共创 | 精准垂类用户，转化率高 |
| 教育行业媒体（教育界、芥末堆）| 提供独家数据/案例换报道 | 品牌曝光 + B 端线索 |

## 6. 关键里程碑与融资策略

### 6.1 Bootstrapping 阶段目标（0-18 个月）

**原则：不依赖融资活下去，每一分钱都花在刀刃上**

| 里程碑 | 时间 | 指标 |
|-------|------|------|
| MVP 上线，获取前 50 个真实用户 | M3 | 50 活跃用户，NPS ≥ 40 |
| 产品市场匹配（PMF） | M6 | 40% 用户表示"非常失望如果产品消失"（Sean Ellis 指标） |
| 盈亏平衡 | M8-M9 | MRR ≥ ¥4.2 万，月增长率 ≥ 15% |
| 规模化验证 | M12 | 400 付费用户，MRR ≥ ¥32 万，Churn ≤ 5%/月 |
| 融资就绪 | M15-M18 | MRR ≥ ¥50 万，连续 6 个月环比增长 ≥ 20% |

**Bootstrapping 期间的资金来源**：
- 创始人自有资金：¥30-50 万（覆盖前 6-8 个月运营）
- 早期收入持续 reinvest，不分红
- 可考虑：接 1-2 个 AI 咨询/外包项目，补充现金流（但不能影响产品进度）

### 6.2 何时考虑融资（指标触发条件）

触发融资讨论的条件（需同时满足至少 3 条）：

1. MRR ≥ ¥50 万，且连续 3 个月环比增长 ≥ 20%
2. 用户留存：M6 留存率 ≥ 50%（即 6 个月后仍在付费的用户比例）
3. 有机获客比例 ≥ 40%（证明产品本身有传播力）
4. 机构客户签约 ≥ 5 家（证明 B 端可行性）
5. 团队：找到 1 名愿意 at-risk 加入的核心合伙人（产品/商业方向）

**避免过早融资的理由**：
- 太早融资稀释股权，且 VC 的 KPI 压力会迫使你追求用户数而非收入质量
- Bootstrapping 期间的每个决策都更接近真实市场信号

### 6.3 融资用途（加速而非存活）

**目标融资规模**：天使轮 ¥500-1,000 万（Pre-A 节奏）

| 用途 | 比例 | 具体内容 |
|------|------|---------|
| 团队扩张 | 40% | 招募产品经理 1 人 + 增长/运营 1 人 |
| 销售/GTM 加速 | 30% | KOL 规模化合作，付费渠道投放测试 |
| 技术基础设施 | 20% | GPU 资源扩容，降低 API 依赖 |
| 市场/品牌 | 10% | 行业会议、白皮书、媒体公关 |

**融资叙事核心**：
- 不是"我们是投资/教育 AI 公司"
- 而是"我们是 AI 基础设施公司，正在用两个垂直赛道验证 AI 超级工具的 PMF，接下来可以快速复制到医疗/法律/金融等更多行业"

## 7. 风险矩阵

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| **大模型 API 涨价或断供**（OpenAI/Claude 限制中国访问） | 中 | 高 | 多模型冗余路由已内置；优先接入国内 API（百炼/混元）作为 fallback；预留 3 个月 API 预付额度 |
| **大厂推出同类产品**（腾讯/字节投入投研 AI） | 高 | 中 | 专注记忆层和工作流深度，不打通用 AI 战；垂直数据壁垒是护城河；早于大厂获得 PMF |
| **金融数据合规风险**（使用 Wind/第三方数据的版权问题） | 中 | 高 | 优先接入有正版协议的数据源；让用户自主上传数据（平台不存储原始金融数据）；聘请兼职合规顾问 |
| **用户数据隐私监管收紧**（《个人信息保护法》执行升级） | 高 | 中 | 从第一天起按最严标准设计数据架构（数据最小化 + RLS）；提前准备等保 2.0 认证 |
| **AI 幻觉导致投资决策错误**（用户因错误建议亏损投诉） | 中 | 极高 | 用户协议明确免责条款；所有 AI 输出标注"仅供参考，不构成投资建议"；关键输出加置信度评分 |
| **PMF 难以找到**（产品做出来没人愿意付费） | 中 | 极高 | 前 50 用户免费但强制访谈；每月做 Sean Ellis 调研；设定 M6 决策节点：不达标则 pivot |
| **创始人单点故障**（独立创业者，无备份） | 高 | 高 | 关键代码 + 文档完整记录；优先找联合创始人或核心员工；购买关键人保险 |
| **数字人技术被更低成本替代**（开源模型追平 HeyGen 质量） | 中 | 中 | AvatarOS 的壁垒不在渲染质量，而在讲师知识图谱整合；产品不过度押注生成质量的差异化 |
| **教育行业政策风险**（新一轮"双减"扩展至成人教育） | 低 | 高 | 避开 K12；专注职业培训/企业培训/知识付费（政策风险最低赛道）；企业版先行 |
| **资金链断裂**（Bootstrapping 期间收入不达预期） | 中 | 高 | 维持 6 个月现金储备 hard line；月度 burn rate 监控；预设"保命收入"方案（AI 咨询外包） |
