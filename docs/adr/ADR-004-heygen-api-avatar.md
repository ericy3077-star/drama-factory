# ADR-004: 数字人引擎前期外采 HeyGen API

## 状态
已采纳

## 背景

AvatarOS 是 Drama Factory 平台的差异化功能之一：允许用户（投资顾问、教育机构讲师）创建自己的 AI 数字人，用于生成讲解视频、课程内容和投资分析播报。

2024 年初评估数字人技术路径时，面临的核心问题：

1. **技术门槛极高**：生成高质量、口型同步准确的数字人视频需要以下技术栈——人脸关键点检测（68点）、语音驱动面部动画（Audio2Face）、高分辨率视频渲染、背景去除与合成、多语言 TTS 适配。每个子模块都是独立的深度学习方向，单人无法短期掌握。

2. **训练数据稀缺**：要训练特定人物的数字人形象，需要该人物的大量高质量视频素材（通常需要 30 分钟以上的录制视频），且素材质量（光线、角度、清晰度）直接决定最终效果。早期用户量不足时，无法积累足够的训练数据。

3. **GPU 成本高企**：视频渲染阶段需要高显存 GPU（A100/H100 级别），按需计算成本约 $2-5/分钟视频，固定保有成本更高。产品 PMF 尚未验证时，这是无法承受的沉没成本风险。

4. **时间窗口压力**：竞品已经开始在教育 AI 领域集成数字人功能，需要在 3 个月内上线该功能以保持竞争力。自研的最短周期估计为 9-12 个月。

5. **用户期望管理**：用户对"数字人"的期望已经被 HeyGen、D-ID 等商业产品拉高，自研早期版本的质量差距会直接影响口碑。

## 决策

**前期阶段（0-18个月）**：外采 HeyGen API，快速上线并验证市场需求。

**具体实现：**
- 使用 HeyGen `/v2/video/generate` API 提交生成任务
- 使用 `/v1/video_status/{id}` 轮询状态（30秒间隔，最多 20 次轮询）
- 视频生成完成后，将视频文件转存到 Supabase Storage（避免 HeyGen URL 有效期限制）
- 通过 Redis Queue + Avatar Worker 管理异步任务队列
- 通过 WebSocket 推送任务进度到前端

**数据积累策略：** 在 HeyGen API 调用流程中，同步记录每次生成任务的脚本内容、用户反馈（是否重新生成、评分）、最终使用情况，为未来自研积累数据资产。

**迁移触发条件预设（18个月后评估）：**
1. 月活数字人生成任务超过 5000 次（HeyGen API 成本超过 $5000/月）
2. HeyGen API 提供了竞品没有的独家功能且定价极为不公平
3. 用户对数字人质量的核心诉求出现明显的个性化需求（现有 API 无法满足）

|------|---------|---------|-----------------|---------|-----------|---------|
| **HeyGen API（外采）** | 2-4 周 | ⭐⭐⭐⭐⭐ 商业级 | ~$500-1500（$0.5-1.5/视频） | 低（依赖第三方） | 中（限于 HeyGen 提供的模板） | 供应商涨价/停服 |
| **D-ID API（外采）** | 2-4 周 | ⭐⭐⭐⭐ 较好 | ~$300-800 | 低 | 中 | 同上，生态较小 |
| **Runway/Stable Video（外采）** | 1-2 周 | ⭐⭐⭐ 一般（通用视频非专用数字人） | ~$200-500 | 低 | 低（非专用数字人产品） | 质量不稳定，无法锁定人物形象 |

## 结论

选择 HeyGen API 外采路线，核心理由是 **用外采成本换自研时间，用这段时间验证市场并积累数据**。

具体权衡：

1. **Build vs Buy 基本原则**：数字人视频生成不是 Drama Factory 的核心能力，核心能力是 AI 驱动的个性化内容理解和用户记忆。数字人是呈现形式，不是壁垒本身。早期不应在非核心能力上消耗工程资源。

2. **质量护城河**：HeyGen 的商业级质量（4K 分辨率、精确口型同步、自然面部表情）是用户实际决策是否付费的关键因素。开源自研方案在口型同步精度上与 HeyGen 仍有 2 年以上的差距。宁愿付 API 费用也不能用劣质产品损害品牌口碑。

3. **数据飞轮优先**：使用 HeyGen API 的过程中积累的用户脚本数据（行业专业内容）和使用行为数据，是未来自研最稀缺的资产。这些数据只有在产品规模化后才能获取，不应推迟产品上线来等待自研就绪。

4. **成本临界点分析**：在月生成量低于 3000 次时，HeyGen API 成本（约 $1500/月）远低于自研所需的 GPU 集群成本（保守估计 $3000+/月，不含开发人力）。临界点约在月生成 5000-8000 次，此时再启动自研或深度定制已有充足的 PMF 验证。

## 后果

**正面影响：**
- 数字人功能从立项到上线缩短到 3 周，成功抢占市场时间窗口
- 商业级视频质量获得早期用户的高度认可（NPS 评分数字人功能满意度 4.3/5.0）
- 工程团队可以将精力集中在 MemoryOS 和 AgentOS 等核心差异化能力上

**需要接受的负面影响：**
- **供应商依赖风险**：HeyGen 可能提价（2024年已有一次涨价，部分套餐价格上涨 30%），或调整 API 限速策略，直接影响用户体验和成本结构。缓解措施：在 AvatarOS 中保持 API 适配层，D-ID 作为备用供应商，切换成本控制在 1 周内。
- **个性化能力上限**：用户无法完全自定义数字人的表情细节、背景、品牌元素，依赖 HeyGen 提供的模板。高端企业客户的个性化需求将受限，是未来自研的主要驱动力。
- **数据隐私考量**：用户脚本内容需发送至 HeyGen 服务器处理，对有数据本地化要求的企业客户不适用。企业版需要提供自有数字人引擎选项。

**18个月后的评估计划：**
- 分析积累的脚本数据质量和数量，评估是否够训练垂直领域数字人模型
- 评估 HeyGen API 成本占总营收比例，是否超过 15% 的健康上限
- 技术评估开源方案（如 MuseTalk、LivePortrait）的成熟度，是否已接近商业级质量
